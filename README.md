# 🎯 Custom PP-if-Miss Predictor for osu!(lazer)

Кастомная модификация оверлея Simplistic для tosu, разработанная специально под механику расчёта PP в osu!(lazer) (Combo Scaling Removal).

В отличие от стандартного счётчика, который показывает сухой теоретический PP за идеальный FC без ошибок, этот патч в реальном времени вычисляет реальный прогноз итогового PP к концу карты с учётом уже допущенных миссов, 100, 50 и сбитого комбо.

## ⚙️ Что изменено в коде (index.js)

1. Гиперболический штраф за промахи под систему CSR:
   Внедрена нелинейная формула расчёта штрафа за миссы и слайдербрейки:
   1 / (1 + (misses * 0.0285) + (Math.pow(misses, 1.45) * 0.0042))
2. Динамическая интерполяция по таймеру карты:
   Прогресс прохождения трека считывается напрямую через WebSocket (menu.bm.time.current / menu.bm.time.mp3). На старте карты плашка отображает 100% прогноз, а к финишу плавно сходится 1-в-1 с фактическим результатом.
3. Постоянная индикация:
   Убрано условие скрытия верхней плашки при отсутствии ошибок — прогноз виден с первой секунды карты.

## 🚀 Установка

1. Установите и запустите [tosu](https://github.com/tosuapp/tosu).
2. Скачайте стандартный оверлей Simplistic во вкладке Available.
3. Замените файлы в папке tosu/static/Simplistic by jassper0/ файлами из этого репозитория.
4. В игре нажмите Ctrl + Shift + Space и добавьте оверлей на экран.
